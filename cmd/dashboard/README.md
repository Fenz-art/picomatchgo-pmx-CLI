# Picomatch Go Validation Platform

A lightweight local dashboard for demonstrating the picomatch Go engine as a production-style validation surface.

## Run locally

```bash
go run ./cmd/dashboard
```

Then open:

- http://localhost:8080/ for the browser UI
- http://localhost:8080/health
- http://localhost:8080/match
- http://localhost:8080/scan
- http://localhost:8080/parse
